List Elements

Lists ใช้สำหรับแสดงข้อมูลในรูปแบบรายการ มี 3 ประเภท: Unordered, Ordered, และ Description

Unordered List (รายการไม่มีลำดับ)

<ul>
  <li>รายการที่ 1</li>
  <li>รายการที่ 2</li>
  <li>รายการที่ 3</li>
</ul>

Ordered List (รายการมีลำดับ)

<ol>
  <li>ขั้นตอนแรก</li>
  <li>ขั้นตอนที่สอง</li>
  <li>ขั้นตอนที่สาม</li>
</ol>

Nested List (รายการซ้อน)

<ul>
  <li>หมวดหมู่ 1
    <ul>
      <li>หมวดย่อย 1.1</li>
      <li>หมวดย่อย 1.2</li>
    </ul>
  </li>
  <li>หมวดหมู่ 2</li>
</ul>

Description List (รายการอธิบาย)

<dl>
  <dt>HTML</dt>
  <dd>ภาษามาร์กอัป - โครงสร้างของเว็บ</dd>
  <dt>CSS</dt>
  <dd>แบบฟอร์มและการออกแบบ - ลักษณะของเว็บ</dd>
</dl>
นโยบายความเป็นส่วนตัว ข้อกำหนดการใช้งาน ติดต่อเรา

สร้างด้วย HTML5, CSS3 & JavaScript
