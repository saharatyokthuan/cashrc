บทที่ 16 — Tools & Resources

สารบัญ Common Mistakes

Tools & Resources (เครื่องมือและทรัพยากร)

Text Editors (โปรแกรมแก้ไข)

  • Visual Studio Code - ตัวแก้ไขที่ได้รับความนิยมมากที่สุด
  • Sublime Text
  • Notepad++
  • WebStorm

Online Tools (เครื่องมือออนไลน์)

  • CodePen - เขียนและแชร์โค้ด
  • JSFiddle
  • W3C Validator - ตรวจสอบ HTML

Resources & Documentation

  • MDN Web Docs - เอกสารอ้างอิง HTML ที่ครอบคลุม
  • W3C Specifications - มาตรฐาน HTML ทางการ
  • Can I Use - ตรวจสอบ browser support
📚 สรุปประเด็นสำคัญ
✅ HTML ใช้สำหรับ structure ไม่ใช่ styling
✅ ใช้ semantic HTML เสมอ (header, nav, main, article, section ฯลฯ)
✅ เพิ่ม alt text ให้รูปทุกรูปสำหรับ accessibility
✅ ให้ label กับ form inputs ทุกตัว
✅ ตรวจสอบไฟล์ด้วย HTML validator
✅ ให้ใส่ใจกับ SEO และ accessibility ตั้งแต่เริ่มต้น
นโยบายความเป็นส่วนตัว ข้อกำหนดการใช้งาน ติดต่อเรา
