บทที่ 11 — Meta Tags และ Document Head

สารบัญ Semantic Elements Attributes (คุณลักษณะ)

Meta Tags และ Document Head

Meta tags ให้ข้อมูลเกี่ยวกับเอกสาร HTML ต่อเบราว์เซอร์และ search engines

Essential Meta Tags

<!-- Character encoding -->
<meta charset="UTF-8" />

<!-- Responsive design -->
<meta name="viewport" content="width=device-width, initial-scale=1.0" />

<!-- SEO -->
<meta name="description" content="คำอธิบายเพจสั้น ๆ" />
<meta name="keywords" content="keyword1, keyword2, keyword3" />
<meta name="author" content="ชื่อผู้เขียน" />
นโยบายความเป็นส่วนตัว ข้อกำหนดการใช้งาน ติดต่อเรา

สร้างด้วย HTML5, CSS3 & JavaScript
