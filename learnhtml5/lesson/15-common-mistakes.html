Common Mistakes (ข้อผิดพลาดที่พบบ่อย)

1. Missing Alt Text

❌ ผิด:
<img src="photo.jpg" />
✅ ถูก:
<img src="photo.jpg" alt="คำอธิบายรูป" />

2. Improper Nesting

❌ ผิด:
<b><i>ข้อความ</b></i>
✅ ถูก:
<b><i>ข้อความ</i></b>

3. Using Too Many h1 Tags

❌ ผิด:
<h1>หัวเรื่อง 1</h1>
<p>เนื้อหา</p>
<h1>หัวเรื่อง 2</h1>
✅ ถูก:
<h1>หัวเรื่องหลัก</h1>
<h2>หัวเรื่องย่อย 1</h2>
<h2>หัวเรื่องย่อย 2</h2>

4. Not Using Labels with Form Inputs

❌ ผิด:
<input type="text" />
<input type="email" />
✅ ถูก:
<label for="name">ชื่อ:</label>
<input type="text" id="name" />
นโยบายความเป็นส่วนตัว ข้อกำหนดการใช้งาน ติดต่อเรา

สร้างด้วย HTML5, CSS3 & JavaScript
