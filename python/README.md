# 🐍 Python สำหรับผู้เริ่มต้น — คอร์สภาษาไทย

เว็บไซต์เรียน Python ตั้งแต่ศูนย์จนเขียนโปรแกรมใช้งานจริงได้
สร้างด้วย HTML5 + CSS3 + Vanilla JavaScript — ไม่ต้องติดตั้งอะไร เปิด `index.html` ได้เลย

## 📑 สารบัญ

### เฟส 1 — พื้นฐานที่ต้องแน่น
| บท | หัวข้อ | สิ่งที่ได้ |
|---|---|---|
| 1.1 | ตัวแปรและชนิดข้อมูล | `int` `float` `str` `bool` |
| 1.2 | รับ-แสดงผล | `input()` `print()` `f-string` |
| 1.3 | ตัวดำเนินการ | `+ - * / // % **` ลำดับความสำคัญ |

### เฟส 2 — เงื่อนไข
| บท | หัวข้อ | สิ่งที่ได้ |

| 2.1 | if / elif / else | ตัดเกรด, ตรวจสอบค่า |

| 2.3 | เงื่อนไขซ้อนและ ternary | `min()` `max()` แทน if |

| บท | หัวข้อ | สิ่งที่ได้ |
|---|---|---|

### เฟส 4 — ฟังก์ชัน
| บท | หัวข้อ | สิ่งที่ได้ |

| 4.2 | พารามิเตอร์ | ค่า default, keyword args |

### เฟส 5 — โครงสร้างข้อมูล

## 🚀 วิธีใช้งาน

**เปิดตรงๆ**
```bash
open index.html        # macOS
start index.html       # Windows
```

**เปิดผ่าน local server (แนะนำ)**
```bash
python -m http.server 8000
# เปิด http://localhost:8000
```

## ✨ ฟีเจอร์

- **สารบัญข้าง** — คลิกกระโดดไปบทที่ต้องการทันที
- **ติดตามความคืบหน้า** — ติ๊กบทที่เรียนจบ บันทึกใน `localStorage`
- **ค้นหา** — พิมพ์คำ กรองบทเรียนแบบเรียลไทม์
- **คัดลอกโค้ด** — ปุ่มเดียวจบ
- **สลับธีม** — สว่าง / มืด
- **Responsive** — ใช้บนมือถือได้

## 🛠 การเพิ่มบทเรียนใหม่

แก้ไฟล์ `js/data.js` เท่านั้น:

```javascript
{
  id: "8.1",
  title: "ชื่อบทเรียน",
  desc: "คำอธิบายสั้นๆ",
  code: "print('hello')",
  out: "hello",
  ex:  "โจทย์ฝึก"
}
```
